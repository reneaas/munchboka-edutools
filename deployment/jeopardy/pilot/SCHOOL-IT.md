# Request for educational categorization

Subject: Educational website category review – jeopardy.munchboka.no

Please review https://jeopardy.munchboka.no/ for classification as an educational
resource, or allow access under the school's approved teaching-resource policy.

Munchboka Undervisningsquiz is a classroom authoring tool for teachers and students.
Users create subject questions and answers for revision, concept practice and
group discussion, organized in a Jeopardy-style category board. It supports
mathematical notation and images. Creating an account requires verification of an
@osloskolen.no email address. Teachers and students can explicitly share a saved
activity by link so recipients can use it without an account; recipients cannot
edit the original. Content is user-authored. There is no gambling, game-currency
purchase or advertising.
