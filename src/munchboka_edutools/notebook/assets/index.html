Munchboka Notebook

En notebook består av tekst og kodeceller. Velg en kodecelle og trykk Shift + Enter for å kjøre den. Variabler huskes mellom cellene.

Arbeidet lagres automatisk i denne nettleseren. Bruk Last ned notebook for å lagre en .ipynb-fil på datamaskinen eller levere oppgaven. Nettleserdata kan bli slettet.

Python lastes ned ved første kjøring; dette kan ta litt tid. Hvis et program ikke stopper, bruk Start Python på nytt. Da slettes variablene, men cellene beholdes.

PYTHON I NETTLESEREN

Prøv, utforsk og finn ut.

Åpne en oppgave eller fortsett med en notebook fra datamaskinen din. Du trenger ikke å installere Python.
